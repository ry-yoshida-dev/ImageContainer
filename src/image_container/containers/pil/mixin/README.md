# mixin

## Overview

Mixins that extend `PILImageContainer` with conversion, geometry, and statistics.

## Components

| Component | Description |
|-----------|-------------|
| [convert.py](./convert.py) | `PILConvertMixin`: NumPy, binary, and grayscale exports. |
| [geometry.py](./geometry.py) | `PILGeometryMixin`: shape and spatial accessors. |
| [stats.py](./stats.py) | `PILStatsMixin`: gray/BGR means and histogram aggregates. |
